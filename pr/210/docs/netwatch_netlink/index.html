Minimal rtnetlink client for netwatch.

Covers exactly the subset of the netlink route protocol that netwatch uses on Linux and Android:

  • dumping links, addresses and routes (Connection for blocking callers, AsyncConnection inside tokio),
  • looking up a single link by interface index,
  • listening to rtnetlink multicast groups for change events (EventSocket).

Messages are parsed into the small typed structs in this crate (LinkMessage, AddressMessage, RouteMessage); attributes we do not use are skipped. On every platform other than Linux and Android the crate compiles to nothing.
